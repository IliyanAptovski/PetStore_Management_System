# 🐾 Pet Store Management System

## Project Overview
An ORM-based Windows Forms application for managing pet store inventory, built with **C#** and **Entity Framework**, and connected to **Firebase** for cloud-hosted data storage. This app allows pet store owners to manage their product data efficiently.

---

## Features
- 🐶 **Cloud-based database** using **Firebase** for real-time storage
- 🛒 **CRUD operations** on pet store product data (Create, Read, Update, Delete)
- 🖥️ Built using **Windows Forms** for the user interface
- 📦 **Standalone Windows installer** — no .NET installation required!

---

## Technologies Used
- **C#** — Programming language
- **Entity Framework** — Object-relational mapping (ORM) for data access
- **Firebase** — Cloud-hosted database
